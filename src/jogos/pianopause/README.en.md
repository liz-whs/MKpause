# PianoPause

**PianoPause** is one of MKpause's self-regulation games. Students play, at their own pace, colored keys that move down the screen, and each touch produces a soft note. At any moment they can pause and do a **guided breathing** exercise.

The game has no score, mistakes, losing or visible countdown: the goal is to slow down, not to compete.

> Addresses requirement [RF02 — Access activities and games](../../../docs/02-requisitos/requisitos-funcionais.en.md) and rule [RN08 — Completing the activity](../../../docs/02-requisitos/regras-de-negocio.en.md). The design rationale is in [Self-Regulation Activities](../../../docs/07-fundamentacao/atividades-de-autorregulacao.en.md).

## How to run

Requirements: **Python 3.10+** and **pygame-ce**.

```bash
pip install pygame-ce
python main.py
```

The main loop is asynchronous (`async def main()` with `await asyncio.sleep(0)`), a format compatible with tools that package pygame games for the browser, such as **pygbag**.

## Screen flow

```text
Start ──(Começar)──► Playing ──(Pausar / Esc)──► Guided breathing
  ▲                     │  ▲                          │
  │                     │  └─────(Continuar / Esc)────┘
  │                     │                             │
  │              (Encerrar or 2 min)            (Encerrar)
  │                     ▼                             │
  └──(Voltar ao início)─ End ◄────────────────────────┘
                          │
                          └──(Jogar novamente)──► Playing
```

Button labels are shown as they appear in the game, in Portuguese.

| State | Screen | What happens |
|-------|--------|--------------|
| `inicio` | Start | Pace selection (**Lento**, slow, or **Moderado**, moderate) and the **Começar** (start) button. Decorative bubbles float in the background. |
| `jogando` | Game | Keys move down in 4 columns. Touching a key plays its note and releases particles. |
| `pausado` | Guided breathing | A circle that expands ("Inspire", breathe in) and contracts ("Expire", breathe out). Game time is paused. |
| `final` | End | A supportive message, the time spent and options to play again or go back. |

Screen changes use a short fade (`opacidade_transicao`).

## Mechanics

### Paces

| Pace | Key speed | Base time between keys |
|------|-----------|------------------------|
| **Lento** (slow) | 105 px/s | 1.15 s |
| **Moderado** (moderate) | 155 px/s | 0.85 s |

The actual interval between one key and the next is `base time × note duration` (1 or 2 beats), which gives the sequence a musical cadence.

### Melodies

The keys follow three fixed musical phrases (`MELODIAS`), played in sequence and in a loop. Each column corresponds to a note:

| Column | Note | Frequency | Color |
|--------|------|-----------|-------|
| 0 | C | 261.63 Hz | Lavender |
| 1 | D | 293.66 Hz | Leaf |
| 2 | E | 329.63 Hz | Sky |
| 3 | G | 392.00 Hz | Dusty Rose |

The sounds are **generated by the code itself** (`criar_sons()`): a sine wave with a light harmonic and a soft attack and decay envelope. There are no audio files. If audio cannot be initialized, the game keeps running in silence.

### No penalties

- A key that reaches the green line without being played simply breaks into particles.
- The counter shows only **how many notes were played**, never mistakes.
- The session ends on its own after **2 minutes** (`DURACAO = 120`) or when the student chooses **Encerrar**.

## Guided breathing

When paused, the game shows a circle that follows an **8-second** cycle:

```text
0 s ──── Breathe in (expands) ──── 4 s ──── Breathe out (contracts) ──── 8 s
```

- The motion follows a cosine curve (`suavizado`) that starts and ends slowly, like natural breathing.
- The size ranges between `ESCALA_MINIMA` (0.75) and `ESCALA_MAXIMA` (1.15) of the base radii (`RAIO_EXTERNO = 100`, `RAIO_INTERNO = 70`).
- An outer halo becomes more visible when breathing in and more transparent when breathing out.
- The cycle always restarts at "Inspire" (breathe in) when the pause begins.

The 4-second inhale and 4-second exhale correspond to 7.5 breaths per minute, a slow pace. See [Self-Regulation Activities](../../../docs/07-fundamentacao/atividades-de-autorregulacao.en.md) for the research behind it.

### Why the circle is drawn this way

The `desenhar_circulo_fluido()` function draws circles with a **fractional radius**: the integer part of the radius becomes the circle, and the decimal part becomes a semi-transparent edge. The circle therefore grows in fractions of a pixel, and the animation does not look "stepped".

An earlier version rescaled an image on every frame (`smoothscale`). This made the motion choppy, caused the center to jitter and was heavy in the browser. The game uses `pygame.gfxdraw` when available; without it, the game falls back to `pygame.draw.circle`, with less smooth motion.

## Code organization

The whole game is in [`main.py`](./main.py). Function and constant names are in Portuguese.

| Part | Functions / constants |
|------|-----------------------|
| Configuration | `LARGURA`, `ALTURA`, colors, fonts, `DURACAO`, `VOLUME_FIXO` |
| Audio | `frequencias`, `criar_sons()` |
| Melody and keys | `MELODIAS`, `obter_proxima_nota()`, `criar_tecla()`, `tocar_tecla()` |
| Particles | `criar_particulas()`, `atualizar_particulas()`, `desenhar_particulas()` |
| Guided breathing | `desenhar_circulo_fluido()`, `desenhar_pausa()` |
| Decorative bubbles | `BOLHAS_INICIO`, `BOLHAS_FINAL`, `criar_bolha()`, `desenhar_bolhas()` |
| Screens | `desenhar_inicio()`, `desenhar_jogo()`, `desenhar_pausa()`, `desenhar_final()` |
| Interface | `texto()`, `botao()`, `desenhar_check()`, `desenhar_nota_musical()` |
| State and input | `mudar_estado()`, `iniciar_jogo()`, `clique()` |
| Main loop | `main()` |

### Common adjustments

| To change… | Where |
|------------|-------|
| Session length | `DURACAO` |
| Volume | `VOLUME_FIXO` |
| Speed of each pace | `velocidade` and `tempo_base` in `main()` and `iniciar_jogo()` |
| Melodies | `MELODIAS` (`(column, duration)` pairs) |
| Breathing pace | the `8.0` s cycle and the `4.0` s threshold in `desenhar_pausa()` |
| Size of the breathing circle | `ESCALA_MINIMA`, `ESCALA_MAXIMA`, `RAIO_EXTERNO`, `RAIO_INTERNO` |
| Movement of the decorative bubbles | amplitude, speed and phase in `BOLHAS_INICIO` / `BOLHAS_FINAL` |

> The button click areas in `clique()` use the same coordinates passed to `botao()`. When moving a button, update both places.

## Current limitations

- **No integration with the platform:** the game does not yet record initial or final mood (RF04, RF06), save the session (RF05) or raise alerts. It runs on its own.
- **Some on-screen text is missing accents** (for example, "Comecar", "competicao", "Voce"). The font displays accents correctly (the breathing screen already shows "respiração"), so they can be fixed.
- **Only Level 1** is implemented.
