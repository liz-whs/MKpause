## Summary

MKpause is a platform that supports **students' emotional self-regulation in the school environment**.

The proposal combines self-regulation resources used directly by students with follow-up mechanisms for the responsible professionals, making it possible to record sessions, emotional states, alerts, notes and other information relevant to each student's follow-up.

The system seeks to organize this process in a structured digital environment, with different access levels according to each user's profile.

The research behind these choices is presented in [Scientific Rationale](../07-fundamentacao/README.en.md).
