## Resumo

O MKpause é uma plataforma voltada ao apoio à **autorregulação emocional de estudantes no ambiente escolar**.

A proposta combina recursos de autorregulação utilizados diretamente pelo estudante com mecanismos de acompanhamento por profissionais responsáveis, permitindo registrar sessões, estados emocionais, alertas, observações e informações relevantes para o acompanhamento do estudante.

O sistema busca organizar esse processo em um ambiente digital estruturado, mantendo diferentes níveis de acesso de acordo com o perfil de cada usuário.
