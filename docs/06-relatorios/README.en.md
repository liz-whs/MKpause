# MKpause Reports

This section contains reports, analyses and supplementary documents produced during the development of **MKpause**.

The purpose of this directory is to keep important records of the development process that complement the project's main documentation.

---

## Contents

This directory may hold documents related to:

- research carried out;
- analyses of existing solutions;
- surveys;
- validations;
- test results;
- usability analyses;
- project progress reports;
- decision records;
- presentations;
- academic documents;
- results obtained during development.

---

## Organization

Documents should have names that make their content easy to identify.

Example:

```text
06-relatorios/
├── README.md
├── pesquisa-exploratoria.pdf
├── analise-de-solucoes.pdf
├── validacao-prototipo.pdf
└── relatorio-final.pdf
```

The structure may be expanded as new documents are produced.

---

## Versioning

Whenever possible, documents that can be kept as text should use formats that work well with version control.

For example:

```text
relatorio-validacao.md
```

instead of keeping only:

```text
relatorio-validacao.pdf
```

When a PDF is required for submission or presentation, both can be kept:

```text
relatorio-validacao.md
relatorio-validacao.pdf
```

This makes it easier to see the changes made over the course of development.
