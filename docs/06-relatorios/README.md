# Relatórios — MKpause

Esta seção reúne relatórios, análises e documentos complementares produzidos durante o desenvolvimento do **MKpause**.

O objetivo deste diretório é manter registros importantes do processo de desenvolvimento que complementam a documentação principal do projeto.

---

# 📌 Conteúdos

Este diretório pode armazenar documentos relacionados a:

- pesquisas realizadas;
- análises de soluções existentes;
- levantamentos;
- validações;
- resultados de testes;
- análises de usabilidade;
- relatórios de evolução do projeto;
- registros de decisões;
- apresentações;
- documentos acadêmicos;
- resultados obtidos durante o desenvolvimento.

---

# Organização

Os documentos devem possuir nomes que permitam identificar facilmente seu conteúdo.

Exemplo:

```text
06-relatorios/
├── README.md
├── pesquisa-exploratoria.pdf
├── analise-de-solucoes.pdf
├── validacao-prototipo.pdf
└── relatorio-final.pdf
```

A estrutura pode ser expandida conforme novos documentos forem produzidos.

---

# Versionamento

Sempre que possível, documentos que possam ser mantidos em formatos textuais devem utilizar formatos compatíveis com versionamento.

Por exemplo:

```text
relatorio-validacao.md
```

em vez de manter exclusivamente:

```text
relatorio-validacao.pdf
```

Quando o PDF for necessário para entrega ou apresentação, ambos podem ser mantidos:

```text
relatorio-validacao.md
relatorio-validacao.pdf
```

Isso facilita a visualização das alterações realizadas ao longo do desenvolvimento.
