# MKpause

Plataforma de apoio à autorregulação emocional e ao acompanhamento
de estudantes no ambiente escolar.

## Sobre o projeto

O MKpause é um sistema desenvolvido com o objetivo de oferecer aos
estudantes recursos de autorregulação, permitindo a realização de
sessões com atividades, vídeos e registro do estado emocional.

O sistema também possibilita o acompanhamento por profissionais da
instituição, como professores, psicólogos escolares e psicólogos
clínicos, respeitando as permissões de cada perfil.

## Principais funcionalidades

- Autenticação de usuários
- Sessões de autorregulação
- Registro de humor antes e depois das sessões
- Atividades e conteúdos de apoio
- Emissão de alertas
- Registro de observações
- Histórico do estudante
- Acompanhamento por profissionais
- Gerenciamento de estudantes e profissionais
- Gerenciamento de vínculos entre usuários

## Usuários do sistema

- Estudante
- Professor
- Psicólogo Escolar
- Psicólogo Clínico
- Administrador
